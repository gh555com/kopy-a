# 剪贴板监控应用

## 功能说明
这是一个基于Electron开发的剪贴板监控应用，当检测到剪贴板内容变化时，会显示一个弹窗并播放音效。

## 主要特性
1. 后台监控剪贴板内容变化
2. 检测到变化时显示弹窗
3. 播放随机音效
4. 支持手动退出（Ctrl+Alt+Q）
5. 窗口自动隐藏和显示

## 使用方法
1. 运行应用：`npx electron .`
2. 复制任何内容到剪贴板，应用会自动检测并显示弹窗
3. 按 Ctrl+Alt+Q 退出应用

## 测试方法
运行测试脚本：`.\test_app_en.bat`

## 技术实现
- 使用Electron框架开发
- 主进程负责创建窗口和监控剪贴板
- 渲染进程负责显示弹窗和播放音效
- 使用IPC通信实现进程间通信

## 文件结构
- main.js - 主进程代码
- renderer.js - 渲染进程代码
- index.html - 弹窗界面
- test_app_en.bat - 测试脚本
